# Slope Stability Monitoring

## Objective

Detect the onset of slope movement before failure, identify the shear surface, and quantify the rate of movement to inform early-warning and remediation.

## Typical instrument array

| Instrument | Purpose |
| --- | --- |
| In-place inclinometer (IPI) array | Continuous profile of lateral movement |
| Vibrating-wire piezometers | Pore water pressure triggering failure |
| Surface tiltmeters | Catch the upper edge of a moving mass |
| RSTAR mesh radio | Brings sensor data back to alert gateway |
