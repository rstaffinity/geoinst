# How to Use This Site

This is a curated **intranet** for the geotechnical instrumentation community, organized around the RST Instruments product portfolio.

## Navigation

- **Top tabs** organize content into 6 main sections: Getting Started, RST Instruments, Reference Manuals, Applications, Manufacturers, and GTI Doctor.
- **Sidebar** expands the section you're currently in.
- **Search** (top of page) indexes the full text of every manual and product page — use it to find an instrument by part name, a parameter by unit (e.g., "kPa pore pressure"), or an application by project type.

## The GTI Doctor

The site includes an optional AI chatbot, [GTI Doctor](../gti-doctor.md), that grounds its answers in the reference manuals on this site. Use it for quick lookups like:

> "What's the typical lateral range of a MEMS inclinometer from RST?"

> "Give me the near-surface installation checklist for a vibrating-wire piezometer in a 50 mm borehole."

The assistant will not invent answers outside its training corpus — if your question is outside scope it will say so.
