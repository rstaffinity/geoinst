# GEO-Instruments

GEO-Instruments focuses on **large-scale infrastructure projects**, providing:

- Satellite loggers
- Locator One GNSS sensors
- Wide-area monitoring for tailings dams

Downloads archive: [geoinstruments.ca/en/downloads/](https://www.geoinstruments.ca/en/downloads/)

Cited in the Mining Glossary PDF as a tailings monitoring reference.
