# Dunnicliff — Geotechnical Instrumentation for Monitoring Field Performance

**Author**: John Dunnicliff
**Edition**: The reference textbook on geotechnical monitoring, used worldwide as the primary standard for planning monitoring programs.

## Why this manual matters

Dunnicliff is the definitive guide for engineers designing instrumentation programs for slopes, embankments, tunnels, dams, and foundations. The book covers:

- Planning methodology (what to measure, where, when)
- Installation guidelines for each instrument family
- Data interpretation and presentation
- Field checklists and quality control
