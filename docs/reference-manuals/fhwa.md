# FHWA Geotechnical Instrumentation Reference Manual

**Source**: Federal Highway Administration (FHWA)
**Purpose**: Primary standard for planning monitoring programs for highway construction, slopes, and embankments.

The FHWA manual complements Dunnicliff with:

- Field checklists for state DOT monitoring projects
- Installation guidelines for inclinometers, piezometers, and settlement systems
- Student exercises for state DOT training programs
