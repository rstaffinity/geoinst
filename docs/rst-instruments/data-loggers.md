# RST Data Loggers

RST data loggers bridge field sensors (vibrating-wire, RS-485, analog) to the RSTAR Affinity mesh network for unattended remote monitoring.

## Overview

- **Channels**: 8–64 vibrating-wire + digital channels per logger
- **Power**: Solar-charged LiFePO4 battery, 1–5 year autonomy between charges
- **Backhaul**: Cellular (LTE / 2G fallback), satellite, or mesh-radio to gateway
- **Remote telemetry**: Pushes to RSTAR Affinity cloud dashboard for real-time alerts
