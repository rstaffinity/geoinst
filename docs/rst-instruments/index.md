# RST Instruments (an Orica company)

**RST Instruments** is a global manufacturer of geotechnical and structural monitoring instruments, specializing in remote wireless data collection networks. RST is now part of **Orica's Digital Solutions / GeoSolutions** group.

> 🌐 **Official site**: [orica.com/digital-solutions/geosolutions/rst-instruments](https://www.orica.com/digital-solutions/geosolutions/rst-instruments)
