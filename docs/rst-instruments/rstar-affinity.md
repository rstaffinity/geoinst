# RSTAR Affinity Platform

The **RSTAR Affinity** platform is RST Instruments' automated data-mesh infrastructure for remote wireless data collection. It aggregates readings from distributed sensors (piezometers, inclinometers, extensometers) into a single cloud-accessible dashboard.

## Overview

- **Architecture**: Mesh-radio sensor nodes → gateway → cloud dashboard
- **Sensors supported**: vibrating-wire piezometers, MEMS inclinometer arrays, extensometers, tiltmeters
- **Power**: Solar-charged battery nodes for multi-year autonomous operation
- **Cellular / satellite backhaul** for sites without line-of-sight to a gateway
