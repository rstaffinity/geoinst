# 

How to copy files from RST FieldPC2&nbsp;to PC or memory stick &nbsp;&nbsp;

Scenario:&nbsp;customer needs to copy the files from from RST FieldPC2.

Solution:&nbsp;Follow the steps in the guide below to do the job.&nbsp;

There are 3 ways to get the files from RST FieldPC2&nbsp;by the use of USB connection, a memory stick or Bluetooth.&nbsp;

3. For Bluetooth Connection.

Ensure the Bluetooth is enabled on the destination computer. Make note of the computer ID, in this case, NB077.

Ensure that the Bluetooth on the Field PC2 is discoverable.

Choose ‘File Explorer’ and select ‘My Device’.

When in ‘My Device’, choose ‘My Documents’.

In ‘My Documents, choose ‘Digital Inclinometer’.

In Digital Inclinometer’, select the Site(s) and Borehole(s) that you wish to download.

In this case, borehole 1, profiles 19 is to be exported.

Once the files have been selected, press Send….

Once the file has been transferred, it will say ‘Done on the Field PC and it will say received on the computer in the location designated below.

&nbsp;

Install Windows Mobile Device Center (64 bit)https://rstinstruments.com/wp-content/uploads/files/Mobile-Device-Center-for-Windows-Vista-and-later.zip

Install WMDC Fixes for Windows 10: https://rstinstruments.com/wp-content/uploads/files/WMDC-fixes-for-Win10.zip

Connect Field PC2&nbsp;to PC using USB cable (microUSB to USB), the following window will pop-up.

Select&nbsp;Connect without setting up your device&nbsp;option.&nbsp;

Select&nbsp;File Management&nbsp;Option and&nbsp;Browse the contents of your device.

Browse the contents of the device to find the files in the Field PC2&nbsp;memory.

Insert a memory stick (formatted in FAT32) into USB socket on FieldPC2

Memory stick will show up as “Hard Disk” in mobile file explorer.

Navigate to datafiles, copy datafiles (press and hold, select Copy).

Navigate to memory stick (Hard Disk) press and hold, select Paste. The files will be copied from the Field PC2&nbsp;to the memory stick.
