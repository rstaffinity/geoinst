# 

Go to https://rstinstruments.com/product/dt-logger-host-software/ at RST website and select Firmware Updates for PC (Logger Firmware Update .exe), then click on the Download Icon to start downloading the software.

After downloading the Firmware Update Utility file, unzip and follow the instructions below.

&nbsp;-------------------------------------------- &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; Logger firmware Update

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; Version 1.XX.0

--------------------------------------------

&nbsp;

The following loggers firmware can be updated using this utility:

DT2011, DT2011B, DT2055B, DT2040, DT4205, RTU, DTL201B, DT2485, DT2350, GAA2820, DTSAA

Instructions for running Logger Firmware Update on a PC

---------------------------------------------------

&nbsp;

1. The Firmware Update will check online for new version. Download current version from www.rstinstruments.com.

2. Connect logger to the PC using communication cable.&nbsp;

3. Run the "Logger Firmware Update.exe" file.

4. Select proper Mode: RS232 for DT2011, &nbsp; USB for all other USB connected loggers.

5. Click "Detect". Click again if no logger gets detected, logger might be in low power mode.

6. Click "Download" to update logger firmware.

NOTE: Logger data will not be affected by firmware update, but it is recommented to download data &nbsp;before attempting firmware update.

Select the connected DT Logger and press the Download button to download the latest firmware in the DT Logger.

When the download is finished, the message will be displayed as shown below.

Click OK and Exit.

Reconnect DT Logger Host Software with the DT Logger to check the latest firmware version in Status tab.

For example, the DT Logger Model DT2055B has been updated to Firmware Version 4.04, which is the latest version at the time of writing this guide.
