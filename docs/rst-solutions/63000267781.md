# 

&nbsp;

Use the Programming Parameters from the Instructions before to set the time for the D’Aerator.

Press and hold the Set button for 8 seconds.

UT - Choose 60 minutes as it should not be left un monitored for a long period of time.

The timer should count down from the set time.
