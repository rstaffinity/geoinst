# 

If you wish to take readings with the RST Digital Inclinometer and save them in .rrp format, the file save format can be changed in the Field PC.

When creating or editing the Borehole file in Digital Inclinometer, select ‘Edit Borehole’&nbsp;

Figure 1. Borehole File Screen.

&nbsp;

On the edit screen, click ‘Data Filename’ , this will allow the user to change the file save format.

Figure 2. Borehole Edit Screen.

&nbsp;

Choose ‘Borehole’ as Filename Type.
