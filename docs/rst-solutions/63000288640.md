# 

Steps to Add a Device:

1.&nbsp;Open GEOExplorerIQ

Begin by launching the&nbsp;GeoExplorerIQ application on your device. Make sure you are logged in with your credentials to access all features. If you encounter any login issues, check your username and password or reset your credentials if necessary.

2. Navigate to the Home Screen

Once the application is open, you will be directed to the Home screen. This is your central hub for managing devices and accessing various functionalities within GeoExplorerIQ. Familiarize yourself with the layout, as it will help you navigate through the application more efficiently.

3. Click the “+” Button

In the upper-right corner of the Home screen, you will see a “+” button. Click on this button to initiate the process of adding a new device. This action will open a menu with several options for device integration.

4. Select “Device”

After clicking the “+” button, a menu will appear. From this menu, select the option labeled “Device.” This will guide you to the section where you can input the details of the new device you wish to add. Ensure you have all necessary information at hand to streamline the process.

5. Choose Your Device Type

For this example, let’s select “Affinity Gateway.” This specific device type is designed to enhance connectivity and data management, making it an excellent choice for your needs. If you are adding a different device, simply select the appropriate option from the list.

6. Enter the Connection Gateway Code and PIN

You will need to enter the connection gateway code and the PIN found on the device label. This code is crucial as it establishes a secure connection between the GeoExplorerIQ and your Affinity Gateway. Remember, this is the same connection code used in the Affinity system, ensuring consistency and reliability in your device management.

7. Complete the Setup

After entering the required information, review your entries for accuracy, then proceed to complete the setup. You should receive a confirmation message indicating that your device has been successfully added.

Conclusion

By following these simple steps, you can easily add a new device to your GeoExplorerIQ. This functionality allows you to expand your network and optimize your operations. If you encounter any issues during this process or have further questions, please feel free to reach out to our customer support team for assistance. Happy exploring!
