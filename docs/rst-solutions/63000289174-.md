# 

Adding Hardware Using&nbsp;the Affinity Mobile App (Recommended)

1. Ensure the antenna is installed on the&nbsp;data logger and the battery tabs are removed.

2. On your Android or iOS device, make sure Bluetooth is on.

3. Launch the RSTAR Affinity field app.

4. Enter the Cloud or Local Server address, and then tap Proceed

5. Enter your username and password, then tap Login

6. In the Select site screen, tap the site where the data logger will be claimed. Data loggers withing range of your device appear on the screen.

&nbsp;

7. Select the data logger you want to claim.

8. Tap Claim, and enter the data logger's info, latitude, and longitude.

9. Tap Initialize battery, and the tap Process. If successful, the Claimed successfully message appears.

Pair data logger with gateway.

In the data logger’s Profile tab, tap Pair gateway.&nbsp;

In the Select gateway screen, tap the gateway you want to pair with the data logger. If successful, the Connected message appears. &nbsp;

Tap the Instruments tab, and then tap Add instrument. &nbsp;

Enter the information of the instrument you want to use to record data, and then tap Next Step.

Tap Complete. If successful, the Configured successfully message appears. &nbsp;
