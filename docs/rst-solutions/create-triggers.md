# Create Triggers

Understanding Triggers, Alarms and Events

Triggers: Conditions based on thresholds

In GeoExplorerIQ, the parameters available for triggers depend on the sensor type and its data source. Each device provides specific measurements (such as pressure, temperature, or battery level), which can be used to define trigger thresholds.

Alarms: Visual Indicators (Colors, Symbols)

Once a trigger condition is met, alarms come into play. Alarms serve as visual indicators that alert you to the status of your instruments. In GEOExplorerIQ, you can customize these alarms using different colors and symbols to represent various levels of urgency. For example, a red alarm might indicate a critical issue that requires immediate attention, while a yellow alarm could signify a warning that should be monitored closely. This visual representation makes it easy to assess the situation at a glance, allowing for quick decision-making.

Events: Actions and Workflows Triggered by Alarms

Events are the final piece of the puzzle, representing the actions and workflows that are initiated when an alarm is triggered. In GEOExplorerIQ, you can configure specific responses to alarms, such as sending notifications to team members, generating reports, or even activating automated systems to address the issue. This seamless integration of alarms and events ensures that you can respond efficiently to any situation, minimizing downtime and enhancing operational effectiveness.
