# How to pair an older inclinometer reel with a newer Field PC

In order to connect an older inclinometer reel with a newer Field PC2, the reel has to be manual paired with the Bluetooth the first time it is connected.

Once the Field PC is paired, it will connect to this reel using the regular connection mode.

To start, click Settings, then Connections, then Bluetooth COM.

Make sure that reel is on, then click Discover Devices.

Once the reel is discovered, select the reel and click Connect at the bottom. Use 1111 for password if asked.

Then, start Digital Inclinometer and use Search button in Bluetooth dialog to search for the reel.

Once the reel is found (marked with F), click “Connect”.

Any subsequent connections will be automatic, ie Digital inclinometer will find reel if the reel is powered on and within range.
