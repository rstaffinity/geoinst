# How to reset Instantel Micromate

If a screen freezes on the Instantel Micromate, and you are not able to do anything or even turn off the Micromate, a hard restart can be initiated to reset the unit. This can happen if the battery is run very low.

To reset the unit:

Plug in the power supply for the Micromate.

Press and Hold the Sensor Check, Setup, Cancel and Start Monitor buttons at the same time and hold for a few seconds until it restarts.

Let the Micromate fully charge before use.
