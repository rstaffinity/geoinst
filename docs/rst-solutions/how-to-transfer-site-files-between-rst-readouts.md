# How to transfer Site Files Between RST Readouts

In this example, an SG350 Readout is used, but the software works the same for all the RST readouts.

In RST Readout Host, connect the old readout and you will be prompted to download the data. When the data is downloaded, check all the check boxes on the left and click on the RST button in the top left, select save. The sites will be saved in an INI file in the readout data folder designated using any name you would like.

In this example, it is saved it as Readout Download_2021, and it is in the directory created when the software was installed on my computer. The location can be changed by clicking The RST button in the upper left and selecting RST Readout Host Options.

Disconnect the old readout and connect the new readout that you wish to load the sites into.

Click on the RST Logo in the top left and select File &gt; Open &gt; select the file you saved from the old readout and the data will be displayed in the Readout Host. The sites will be displayed on the screen.

Click ‘Upload Sites’ and wait for the task bar at the bottom to indicate when it has been uploaded.

Once it is uploaded, you will have all the data and sites in the new VW2106 Readout.
