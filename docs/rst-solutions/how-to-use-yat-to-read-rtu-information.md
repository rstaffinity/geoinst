# How to use YAT to read RTU information

Download YAT Terminal program from here: https://sourceforge.net/projects/y-a-terminal/files/YAT-2.1.0_x86_%2832-bit%29.zip/download

Connect a Laptop running YAT terminal software with the RTU with an USB Type-B cable.

Open YAT terminal program, it will detect the COM Port that is connecting and a blank widow “Monitor”.

Type in Send Text box INFO and press Send Text to get the detailed information of the RTU.

Type in Send Text box RLC and press Send Text to get the detailed configuration of the DT Loggers in the RTU.

Type in Send Text box RLD and press Send Text to get the detailed data values of the DT Loggers in the RTU.
