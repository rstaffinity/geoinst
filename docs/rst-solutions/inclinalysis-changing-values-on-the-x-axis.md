# Inclinalysis - Changing Values on the X Axis

Here are the instructions to change the axis values on Inclinalysis.

To keep settings, save view:

From main menu, click View, then save view as. Type in some custom view name.

Then, in the future, use View-&gt;Open view dialog to open modified view.

Right-click on the axis, uncheck Center Graph and Auto.

Type in desired minimum and maximum.

Click OK.
